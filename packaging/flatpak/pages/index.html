coroom para Linux

Repositorio Flatpak firmado · versión @VERSION@

Instalado desde aquí, coroom se actualiza solo: avisa cuando hay una versión nueva, la baja por el portal de Flatpak y se reinicia con ella. Cada actualización baja solo lo que cambió.

Instalar

Con el gestor de software del escritorio (GNOME Software, Discover):

Instalar coroom

O en una terminal (el runtime llega de Flathub si no lo tienes):

flatpak install --user @PAGES_URL@@APP_ID@.flatpakref

El .flatpak de cada publicación trae este repositorio ya configurado: instalarlo es lo mismo.

Añadir solo el repositorio

flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak remote-add --user --if-not-exists coroom @PAGES_URL@coroom.flatpakrepo
flatpak install --user coroom @APP_ID@

Si ya tenías coroom

Las versiones anteriores al repositorio no saben actualizarse. Instala esta una vez y quita la vieja, que queda en la rama master:

flatpak uninstall --user @APP_ID@//master

Desde ahí, flatpak update también la actualiza.
